Điền API key mà không cần sửa JSON

Mỗi ngăn dành cho một nhóm giải đấu. Bạn dán các key có cùng quyền xem giải vào ngăn đó. Công cụ kiểm tra định dạng rồi xuất file để bạn cập nhật lên GitHub.

Các ngăn API

Mỗi ngăn tối đa 8 key. Mỗi cấu hình tối đa 12 ngăn và 48 key tổng cộng. Ngăn chỉ là tên nhóm, không phải tài khoản SoccerSAPI.

Xuất cấu hình để BinTV đọc

Trước tiên hãy kiểm tra các ngăn, sau đó Tải file JSON hoặc Sao chép JSON. Tại GitHub, mở file soccer-key-pools.json, chọn biểu tượng bút chì, dán thay nội dung cũ và nhấn Commit changes.

Mở GitHub để dán ↗
Key trong GitHub Public là công khai.Dùng key thử nghiệm có thể thu hồi. Công cụ này không gửi key đến máy chủ nào khi bạn nhập hoặc xuất; nút “Lấy cấu hình từ GitHub” chỉ đọc tệp công khai. Khi Commit lên GitHub, key sẽ hiển thị trong file và lịch sử commit.
